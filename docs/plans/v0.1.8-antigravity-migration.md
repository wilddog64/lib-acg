# Task Spec: v0.1.8 — Refactor Gemini CLI to Google Antigravity CLI (`agy`)

**Repository:** `wilddog64/lib-acg`
**Branch:** `feat/v0.1.8`
**Target Version:** `0.1.8`

---

## 1. Context & Goal

Google has retired the legacy Node-based `gemini-cli` (installed via `@google/gemini-cli`) and replaced it with the Go-based **Google Antigravity CLI (`agy`)**. 

To align with this platform change, `lib-acg` must update its browser automation routines to:
1. Target the new `agy` CLI integration surface.
2. Rename references from the legacy "Gemini browser" / `gemini` prompts to "Antigravity browser" / `agy` prompts.
3. Migrate execution arguments from legacy `--yolo` / `--approval-mode yolo` to `agy`'s new `--dangerously-skip-permissions` flag.

---
